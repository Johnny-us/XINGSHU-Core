# 本地运行器开发示例

本批次只增加两个独立的 `experimental / synthetic-only`（实验性／仅合成数据）示例，不改变 Core 的版本、默认开关、治理效力或激活状态。

| 示例 | 提供的内容 | 不包含的能力 |
|---|---|---|
| [macOS 假资料运行器](../examples/macos-local-runner/README.md) | 中文 AppKit 源码、固定假资料、本机编译及合成生命周期验证 | 正式本人授权、真实AI、个人知识库、安装及升级 |
| [公开口令校验](../examples/public-probe-contract/README.md) | 请求／回复一致性、超时／停止／重复及准确旧视图等待的标准库参考实现 | 账号、网络、宿主消息发送、受信回执签发或真实资料权限 |

平台专用演示位于 `examples/`，不放进平台无关的 Core 实现。现有 Core、Schema、CLI、P5、默认行为和 Personal Instance（私人实例）采用关系保持原状。

## 验收层级

源码存在、合成测试通过、PR（代码审查请求）、CI（远端自动检查）通过及公开发布是分别记录的状态。它们都不自动代表真实使用、本人授权、来源接通、正式部署或生产就绪。

本批次公开检查只针对本仓库的示例。任何其他实现的真实连接结果都不能转移为本公共示例的验收。后续真实能力仍须分别实现受控执行、可信授权、来源核验、重开接续及撤销拒读；外部知识地图属于之后的独立集成。

仓库中不包含私人路由、账号、设备绑定、知识正文、审批证据、审计报告、运行数据库或已编译的应用包。本批次不创建 Tag 或 Release，不自动采用公共版本，不激活任何正式运行环境。
