# macOS 假资料运行器示例

状态：**experimental / synthetic-only（实验性／仅合成数据）**。

这是原生 AppKit 中文界面的源码示例。它只读取编译时放入应用包的一篇假资料，演示启动、单次测试许可、来源摘要、进度接续、撤销和停止。不加载个人知识库、模型客户端、凭据或 MCP（模型上下文工具协议）。

## 本机验证

需要 macOS、Apple Command Line Tools（苹果命令行开发工具）和 Python 3.9 或更高版本，不需要第三方 Python 包。从仓库根目录运行：

```sh
python3 -B -I -S examples/macos-local-runner/verify.py
```

脚本在新建的专用临时目录编译并临时签名应用，实际运行命令行合成场景。它验证沙盒拒绝读取／写入包外假文件及本机网络、并发单次交付、撤销、过期、异常退出和重开后拒绝旧许可。GUI（图形界面）源码包含在 `src/main.m`；此命令不打开界面，也不验证人类点击。

成功和失败的应用包都会随本次临时目录清除，不安装应用，不改动既有应用。本示例可能在自己独立的 macOS 容器内留下合成进度数据；这些不是个人知识或正式运行状态。

## 使用边界

- 测试按钮与 CLI（命令行）场景只生成假资料测试状态，不是本人授权证明，不签发正式 P5 许可。
- 单次测试许可绑定当前进程、会话、包内假资料和用途；最长60秒。重开只接续进度，不接续许可。
