# 公开口令读回校验示例

状态：**experimental / synthetic-only（实验性／仅合成数据）**。

此模块演示怎样核对“一次公开请求及其独立回复”的数据一致性。它不发送消息、不连接账号、不调用宿主工具，不提供真实本人确认或私人读取功能。修改常量也不会增加发送能力。

从仓库根目录运行标准库合成检查：

```sh
python3 -B -I -S examples/public-probe-contract/verify.py
```

`protocol.py` 只接受固定的合成任务和保留的示例端点编号。检查涵盖请求编号、范围摘要、发送时间预算、完整请求文本、角色、独立消息编号、新鲜回复、重复交付、停止、超时和多余工具项目。已准确登记的发送前旧视图只能返回 `WAIT`（继续等），不能作为本次成功回复。

这里的回执、端点、范围摘要和批准事件全是调用方提供的合成输入；校验器不证明这些输入真实、可信或获得本人授权。真实适配器必须另行解决受信事件、实际发送证据、来源真实性与强制执行边界。

主机桥接示例使用 macOS／Linux 的 `CLOCK_MONOTONIC_RAW`（跨进程内核单调时钟）。其他平台需要单独实现并验证时钟适配，不能悄悄改用进程起点不同的时钟。

本示例不安装到 Core，不激活 Runtime（运行环境）或正式 P5，不继承任何私人实例的真实试验验收。许可证继承仓库根目录的 Apache-2.0。
