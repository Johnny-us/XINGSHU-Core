# 星枢换窗接续

这是可独立安装的在线操作流程，不要求安装星枢 Core。技能文件不提供聊天连接器、账号权限或后台程序。只处理用户已授权的当前任务。

先读用户整句意图。仅明确要求执行换窗、建立 Codex 与普通 Web 对应聊天、恢复已有换窗运行时进入执行分支。提到或选择技能、检查/审查/修改技能、询问检测状态及讨论方案走维护或说明分支，不建聊天、不发送交接。明确要求实际双端验收时，只在该次测试范围内建立对应聊天。Do not start rollover for skill audits or status questions.

## Web 默认通道

普通 Web 的界面操作默认使用 Chrome 电脑操作：读取当前 Computer Use（电脑操作）文档，通过原生应用接口读取窗口文字、截图、点击和输入；macOS 使用支持的 `cua.getApp('com.google.Chrome')`。`cua.getBrowser(...)`、`getTab(...)` 和 Playwright 浏览器接口属于其他通道，不能当作原生 Chrome 操作。

Chrome 扩展与内置浏览器分别核验。除用户明确指定外，不先试这两个备选；默认通道不可用时保存缺口，仅使用获允许、符合本次范围且实际可用的备选。读取 [通道与恢复](references/browser-channels.md)，不通过别名或其他技术绕过安全禁止。

## 确认来源、工具与进度

- 默认双端；明确“只换 Codex”时采用单端模式。用户只要求继续原聊天时，不擅自创建。
- 从可信宿主核对源聊天、项目和主机。同标题、目录或账号不能证明当前身份。项目归属为空不单独阻断；无法取得源身份时先保存可核实进度，停止外部创建。
- 读取授权工作区的 AGENTS.md、当前任务和明确恢复指针。只有项目声明星枢根时，才验证 XINGSHU_ROOT.md 与适用治理/绑定/协作规则；没有私人实例文件也能使用本技能，不复制他人的配置。
- 继承任务编号、版本、来源范围、已完成/未完成、下一步、停止点和旧未确认投递。指针冲突时复核，不按日期、标题或同账号自行选择。
- 实查官方创建、项目归属、交接输入、模型实读、有界接受与返回实读能力。普通 Web、ChatGPT Work 与 Codex 分别识别，Work 不能冒充普通 Web。双端缺必要接线能力时保留两端原页，不默默改成单端；导航只在请求显示页面时检查。

## 保存、创建与返回

执行前读 [交接契约](references/handoff-contract.md)。使用已有任务恢复记录；没有时，在授权工作区的 `.xingshu-chat-continuity/` 下建立每任务独立记录，用 `current.json` 明确指向运行目录。记录留在本机，不上传。目录使用安全本机标识，不直接拼接外部任务文本。

外部动作前保存唯一 operation_id、意图、有效载荷摘要和原任务指针。Codex 使用官方项目/聊天工具，默认本地、不建新工作树；普通 Web 默认用 Chrome 原生界面。实际编号与归属、输入核对、模型实读、有界接受和源入口返回分别取证，不由单个“已打开/已提交”回执推断后续完成。

第一端等待对应端编号时标 `PENDING_COUNTERPART`；真实编号产生后只补充本轮对应关系，不重发旧业务。返回注明原生主动返回或在线宿主辅助返回。后者是当前执行者实际读取两端回执，再回传到已核验源入口，不证明 Web 自主发送或后台回调。仅链接或新页自称“已返回”不足以完成。

## 导航、恢复与停止

默认保留原聊天、不自动跳转。用户明确要求打开对应窗口后，身份与接续通过才执行该次导航；不跳转不影响阶段一的建窗与接续完成。

恢复先读本任务明确指针，再读已知 run_path，最后核对原 operation_id。已完成的重复调用返回现有地址；已采用业务按原状态恢复。只有确认首次运行或完成前序后的明确再次换窗请求才建新运行。已有意图却丢失记录时停止，不另造编号。

暂停/取消停止相应动作并保留恢复点。安全禁止停止被禁止动作，不绕过；无关备选故障不阻断获允许且实证可用的默认通道。身份、归属、版本、授权冲突及本轮 UNKNOWN 停止受影响步骤，保存 blocked（受阻）或 pending_recovery（待恢复），核对原操作，不盲重试。明确隔离且不影响本轮的历史 UNKNOWN 原样保留、不重发、不清除；依赖不清或仍影响旧业务则停止该业务。正式业务停止点独立保持。

## 回执与维护

先说接续完成、部分完成或受阻，再列进度保存、各端创建/实读/接受/返回/导航、新地址与剩余项。双端证据完整可说“对应聊天与接续已完成；原窗口保留，未自动跳转”。原业务完成、正式绑定采用、客户端发现、部署和长期稳定分别报告，不把本轮通过升级为它们完成。创建成功的 Codex 聊天附宿主要求的创建指令。

本技能执行不发布、不改治理或正式绑定、不扩来源/账号权限、不启后台。回滚技能文件不自动删除真实聊天或未知投递。维护读 [评测范围](references/evaluation.md)；`scripts/validate_run.py` 是可选离线状态检查，只读 JSON，不调用工具、不执行部署、不代替实证与授权。
