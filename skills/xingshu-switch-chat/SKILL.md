# 星枢换窗接续

这是可独立安装的在线操作流程，不包含聊天连接器或后台程序，不要求安装星枢 Core。使用当前回合真实可用的官方工具；技能文件存在不证明两端已接通。只接续用户已授权的当前任务，不启动无关任务。

## 确认入口、范围与工具

- 用户询问提示词、要求安装或编辑技能时，不执行换窗。用户只要求继续现有聊天时，不擅自新建；仅在明确要求新聊天或换窗接续时创建。默认双端；明确“只换 Codex”时采用单端模式。
- 从可信宿主上下文核对当前聊天、主机及项目；不能用相同标题、目录或账号猜测源身份。项目归属为空不单独阻断，但不能取得源聊天身份时停止外部创建。
- 先读当前工作区适用的 AGENTS.md、当前任务与明确恢复指针。如果项目声明星枢根，再验证根入口及适用治理、绑定和协作规则。没有私人星枢文件的用户使用当前授权工作区，不复制别人的实例、配置或聊天编号。
- 继承任务编号、版本、产物摘要、已完成进度、授权和未确认投递。当前记录冲突时核对明确指针；不能按日期或标题自选，不能借换窗清除旧 UNKNOWN。
- 实查创建、目录读取、交接投递、模型实读与结果读回能力。普通 Web GPT、ChatGPT Work 和 Codex 是不同目标；不得用 Work Cloud 新任务代替普通 Web 建窗。双端模式缺任一必要接线能力时，两端都保留原页，只保存恢复点并说明缺口；不默默降成单端。
- 导航只在用户明确要求显示目标页面时检查。没有导航能力不单独阻断已具备工具的建窗接续。工具名称出现在文件里、写入卡片或生成网址，都不算真实连接。

## 保存交接与创建意图

使用项目已有的任务恢复记录；没有时，在当前授权工作区创建 `.xingshu-chat-continuity/`，不要上传其中的聊天身份或进度。每个任务使用独立记录子目录，以其中的 `current.json` 明确指向本任务的运行目录，保存 task_id、源聊天、run_path 和版本。目录名使用本机生成的安全标识，将真实任务编号保存在记录中，不直接把外部文本拼成路径。已有指针只更新同一任务的接续字段，不覆盖无关任务或原进度；同一任务正在被另一运行修改时停止并核对，不能并发创建。

在外部创建前保存运行记录与每一端唯一的 operation_id、创建意图和状态。交接包只包含：当前目标、任务和版本、必要产物摘要、完成事项、未完成项、下一步、授权来源、原入口、有效返回入口及旧未确认投递清单。使用用户授权的必要来源，不整本复制聊天，不包含凭据。

恢复时先读本任务的明确指针，再读本轮已知 run_path，最后核对原 operation_id 的宿主记录。发现旧意图但记录缺失、指针冲突或提交未知时停止；不能新造 run_id 或消息编号重试。已完成的重复调用返回既有结果。用户从验证过的接续聊天明确要求再换一次时，才建立下一运行并记录前序。

## 创建、实读与接续核验

1. Codex 创建前先用实际 `list_projects` 确认项目，再用官方 `create_thread` 创建同一项目的接续聊天。无项目时按宿主支持使用项目外聊天，不借机建新项目；不默认新工作树或分支。交接注明承接原 task_id，避免重复执行已完成事项。异步返回的 clientThreadId 不能当成正式 threadId；等待真实就绪并核验身份。
2. 普通 Web 只使用当前已连接、获授权且可实读的官方工具或受支持界面。核对新页真实编号、项目、主题和版本。创建或投递超时、状态未知时保存 UNKNOWN 并核对原操作；禁止盲目重复建页或重发。新页出现后验证失败，保留为未采用页，不删除，也不替换原对应关系。
3. 所请求端的实际模型必须读取同一任务、版本和交接内容，确认已完成事项与下一步；区分宿主接受提交、实际输入、模型读取、接续确认、业务结果和独立审查。目标自己说“收到了”不能代替输入或身份实证，新聊天回复也不代替独立验收。
4. 双端需完成两个方向的交接输入核对、模型实读和确认读回，并完整核对旧未确认投递。不得因其中一端成功而宣布双端完成。明确单端模式只核验请求端和必要依赖，并说明 Web 保留原页。
5. 复用项目已有、获授权的接续和去重实现。没有该实现时保留交接记录及候选对应关系，不发明库方法或直接改写正式路由。已有正式绑定保持；本技能不自行采用新正式端点。正式业务采用与本轮窗口接续分别报告。
6. 验证通过后保存实际地址和证据，将接续确认或本轮结果读回原入口或已核验的有效返回入口。业务恢复按原采用状态进行，不重建、不重发；源聊天保留。单独建立聊天或保存交接包不算完成。

## 导航与停止

默认留在当前页面。只有用户明确要求“接续核验完成后，打开对应窗口”时，才在身份和接续验证通过后执行该次导航。Codex 可用时使用官方 `navigate_to_codex_page` 打开精确聊天；Web 使用受支持操作打开精确地址，分别记录回执。在线协商不代替用户的导航选择，不建立长期自动切换或后台权限。

用户暂停、取消或要求不跳转时停止相应操作并保留恢复点。工具缺失、安全禁止、身份/归属/版本冲突、来源未授权、未知提交或旧消息未核清时，保存 `blocked` 或 `pending_recovery`，具体说明原因和恢复动作；不把找不到记录当成首次运行。

## 回执

先说完成、部分完成或受阻；列出进度保存、各端实际创建/输入实读/模型读取/接续确认/导航状态、返回入口、新地址及剩余项。工具不足时只报告已保存和已核对的事实。双端证据完整时可说“对应聊天与接续已完成，原窗口保留，未自动跳转”；不因默认没有导航而判定接续失败。

原业务是否完成、正式路由是否采用、技能是否被客户端发现及另一台实体机器是否验证，应分别说明。创建成功的 Codex 聊天按宿主要求返回创建指令。安装、脚本检查或模拟推演不算真实双端换窗验收。

本技能执行时不发布内容、不改治理或正式绑定、不取得账号权限、不启后台。安装也不会把同名技能装进普通 Web GPT。
