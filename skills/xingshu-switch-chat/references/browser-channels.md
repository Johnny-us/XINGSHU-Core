# 浏览器通道与恢复

本文件落实本技能的 Chrome 电脑操作默认路线。只在当前在线回合、当前任务授权和工具允许范围内操作。

## 三种通道

| 通道 | 接法 | 可验证的证据 |
| --- | --- | --- |
| Chrome 电脑操作，默认 | Computer Use 原生应用接口；macOS 为 `cua.getApp('com.google.Chrome')`，再用应用的文字读取、截图、点击和输入 | 当前窗口的真实标题、地址、页面文字、截图及操作后状态 |
| Chrome 扩展，备选 | `cua.getBrowser(...)` / 浏览器标签接口，通过已连接的 Chrome 插件读取和操作网页 | 对应资料的扩展连接、真实页面读取及操作结果；“安装了扩展”不足以证明可用 |
| 内置浏览器，备选 | 当前聊天的应用内网页面板与 `iab` 浏览器接口 | 当前源聊天绑定、真实页面读取、截图及操作后状态；标签元数据不足以证明可用 |

三个通道不是三种聊天账号，也不是三个新任务。Chrome 的两条通道可以操作同一资料中的同一网页，但连接与失败状态不同。Chrome 电脑操作不依赖 ChatGPT 浏览器扩展来读取窗口；仍受电脑操作工具、系统权限及安全检查约束。

## 默认 Chrome 电脑操作

1. 读取当前 Computer Use 文档，遵守首次调用和重置后的入口规则。使用原生 Chrome 应用接口；默认路线不要求先连接或调用扩展，也不使用浏览器 Playwright 接口充当原生应用操作。
2. 核对当前窗口和已确认的资料、账号及目标聊天。资料选择页、恢复旧标签提示或登录页都只是中间状态；不得据此声称目标聊天已读。不要用固定的私人资料名称或页面元素编号；没有充分证据时保留未确认状态。不得恢复无关旧标签或改动现有账号来完成接续。
3. 已有正确目标页面时继续使用。需要打开页面时，按当前工具规则新建本轮标签，避免覆盖用户其他网页。通过当前可见地址或已获授权的精确目标定位；打开后实读标题、地址、项目与对话正文。
4. 每次点击、导航、滚动或输入后读取最新界面，再决定下一步。数字元素编号只用于刚取得的界面。截图只保存真实返回的图像，按实际格式命名；失败时写 `NOT_SAVED`，不生成替代画面。
5. 读到源聊天正文后，按主技能的创建意图、唯一操作标识、上下文、进度和返回核验流程继续。通道验证只做必要的只读或可逆操作，不额外发送测试消息或创建测试聊天。正式创建、交接、接受继续和结果返回仍分别取证。
6. 结束时只清理本轮临时标签。未完成接续所必需的页面可保留，并记录用途；保留用户原有标签、聊天和正式绑定。

## 故障时分清步骤

记录实际失败的是：找到窗口/标签、打开页面、读取文字、截图、点击/输入、提交，还是返回核验。用户能看见页面只证明页面显示；工具能列出标题或返回“已打开”也不等于已读正文。

- 读取超时：保存通道和已完成步骤。可做一次与现有证据相符的受支持连接恢复，再用同一目标复测；同样的错误重复时改做日志诊断，不循环重试。工具内核重置只重置工具会话，不代表应用后台连接已经修复。
- 创建或投递超时：先按主技能核对原操作和目标页面。改通道时继承原操作标识、未知状态和去重清单；不能把新通道当作再次创建或重发的理由。
- 扩展连接：依当前目录核对资料、扩展身份及返回的浏览器类型。工具重置或目录变化后重新读取当前编号对应关系，不能沿用旧数字编号；能够使用已核验的扩展身份时优先使用。空标签列表不证明扩展断线。
- 内置浏览器连接：核对当前源聊天绑定。正式打开工具返回 `queued` 时表示等待显示，不是页面已经打开。只在 用户本次或此前有效授权允许显示该聊天时，用正式导航工具显示精确源聊天；随后从当前目录核对实际标签，不能只依据导航回执。
- 修复验收：真实文字读取、截图、必要的可逆操作与操作后再次读取均通过，才可报告该通道本轮验收通过。某项未通过则记部分恢复或受阻；一轮通过不证明长期稳定，也不代表换窗接续整体完成。

不得通过 shell、AppleScript、私有接口、修改应用包或转换应用别名绕过电脑操作工具的安全禁止。另一浏览器仅在它本身获得允许、且符合当前任务授权时可用，不能绕过同一被禁止动作。应用内部连接无法通过现有正式工具修复时，保存最小日志、源聊天编号、操作和恢复点；如实说明尚未完全修复，不扩大权限、清除网站数据、退出账号或影响其他任务来强行达成结果。
