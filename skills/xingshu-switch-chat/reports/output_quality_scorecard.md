# 公开技能品质与证据范围

版本0.2.0，成熟度 experimental / scaffold（实验流程）。本次为通用修正的公开候选，不复制私人安装、现场截图、真实聊天/项目编号或运行状态。

提供：22条启发式触发夹具，23个离线合成状态案例；可选只读校验器严格比较任务、版本、进度和停止点，拒绝本轮未知提交、越权导航、正式改绑、后台及旧任务重发。数据标签分别为 HEURISTIC_TRIGGER_FIXTURE_NOT_MODEL_EVIDENCE 与 SYNTHETIC_STATE_FIXTURE。

安装、摘要与可重现打包由仓库检查工具验证；这些检查不代表双端真实聊天验收。当前包的真实端点和客户端发现必须由采用者重新验证。

missing evidence（证据缺失）：公开包在独立实体机器的完整双端测试、模型驱动盲测、真实无技能基线、长期成功率、无人值守和 Web 自主返回。不能把提供合成案例、源码审查或某个私人实践的结果当成这些证据。

版本更新不改治理或正式绑定，不自动发布用户内容、不启动后台。失败时保留原聊天、历史未知与本机恢复点。
